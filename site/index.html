Everything you need to run your week

One app for the things you do every day. Nothing more, nothing hidden.

  • Tasks that fit your life

    Priorities from Critical to Low, due dates with optional time, subtasks, tags and categories. Repeat daily, on weekdays or every few weeks. The quick-add line sets priority, category and date in one go.

  • Weekly planner and calendar

    Drag tasks between days, or switch to an hourly grid and plan with time blocks you can move, resize and create. Outlook and Google calendars can appear read-only in the desktop app.

  • Weekly notes

    Keep thoughts and ideas by week, with titles, tags, pinning and search. Not everything has to be a task. The daily plan adds a main goal, a top 3 and a reflection.

  • Reminders

    Get reminded at the due time, or 5, 15 or 30 minutes, 1 hour or 1 day before. Snooze for 10 minutes. Notifications also appear while the desktop app waits in the tray.

  • Document editor

    Write documents like in a word processor: headings, tables, images, formulas and code with syntax highlighting. Import and export Markdown, export to PDF.

  • Focus mode

    Hide everything except one task and work with a Pomodoro timer. Choose your top 3 for today and keep the day in view.

  • Statistics

    See what you finished today, this week and this month, plus completion rate, streak, a weekly chart and an 8-week trend.

  • Designs and themes

    Seven designs from Classic to Tokio and Paper, light or dark, your own accent color, fonts, density and text size. Available in English, German, Turkish and Spanish.

  • Windows, Linux and browser

    Desktop apps for Windows and Linux that can update themselves, with an optional tray icon and a global shortcut for quick capture. Or simply open it in your browser.

Your data stays yours

Todo4Me runs offline on your computer. There is no account, no cloud and no tracking. It is open source under the MIT license, so you can check this yourself.

  • Offline first

    Everything works without an internet connection.

  • No account

    Install it and start. No sign-up, no email address.

  • No cloud, no tracking

    Nothing is uploaded and no usage data is collected.

  • A folder on your computer

    Windows: %APPDATA%\Todo4Me
    Linux: ~/.config/Todo4Me
    Updating, reinstalling and uninstalling do not delete it.

  • Backups you control

    A daily automatic backup of the last 14 days, plus JSON export and import whenever you like.

  • Honest about the network

    The desktop app goes online only to check for updates and, if you set them up, to load subscribed calendars.

Free for Windows and Linux (x86_64). Choose your system.

Latest version: see the release page

Todo4Me is available for Windows and Linux. On other systems, such as macOS, iOS or Android, use the browser version.

Recommended for your system

Windows

  • Installer (recommended)No admin rights needed. Creates a desktop shortcut and a Start menu entry, and updates itself.
    Download

    Todo4Me-Setup-*.exe

  • PortableRuns without installation, for example from a USB stick. Does not update itself.
    Download

    Todo4Me-*-portable.exe

SmartScreen: the files are not digitally signed. If Windows shows “Windows protected your PC”, choose More info, then Run anyway.

Your data lives in %APPDATA%\Todo4Me. Installed and portable versions share it.

Recommended for your system

Linux

  • Ubuntu, Debian, Mint.deb package, recommended on Ubuntu
    Download
    sudo apt install ./Todo4Me-*-amd64.deb
  • Fedora, RHEL, openSUSE.rpm package
    Download
    sudo dnf install ./Todo4Me-*-x86_64.rpm
  • Any distributionAppImage, updates itself
    Download
    chmod +x Todo4Me-*.AppImage && ./Todo4Me-*.AppImage
  • Any distribution.tar.gz, no installation. Run todo4me from the extracted folder.
    Download
    tar xzf Todo4Me-*-x64.tar.gz

AppImage needs FUSE 2. On Ubuntu 22.04 and newer install it with sudo apt install libfuse2t64 (older: libfuse2), or start the AppImage with --appimage-extract-and-run.

On Ubuntu 23.10 and newer, the deb and rpm packages keep Chromium’s sandbox through an AppArmor profile, which is why they are recommended there.

Your data lives in ~/.config/Todo4Me.

No installation needed?

Todo4Me also runs in any current browser. Your data stays in that browser.
